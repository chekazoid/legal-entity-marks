# Проверки

Для тестов нужны PHP с mbstring и DOM. Запуск без установки PHP локально, из корня плагина с заранее подготовленным образом:

    for f in tests/test_*.php; do docker run --rm -v "$PWD":/app php:8.3-cli-alpine php /app/$f; done

Или по одной:

    docker run --rm -v "$PWD":/app php:8.3-cli-alpine php /app/tests/test_morph.php

- `test_morph.php` - склонение фамилий и имён, определение рода
- `test_match.php` - поиск сущностей в тексте, режимы одиночной фамилии
- `test_context.php` - правило «только в цитатах и ссылках»
- `test_quoted.php` - алиасы, которые ищутся только в кавычках
- `test_separator.php` - разделители между словами названия
- `test_generic.php` - защита от общеупотребительных оборотов
- `test_asterisk.php` - звёздочки, поставленные редактором вручную
- `test_import.php` - разбор записей реестра: хвосты названий, алиасы, домены
- `test_links.php` - что находится в ссылках и что удаляется из текста
- `test_data.php` - договор с комплектными данными: поля, типы, отсутствие мусора
- `test_channel.php` - канал реестров: какие реестры ведёт, разбор отказов
- `test_fetch.php` - результат обновления через канал, диагностика и предупреждения при переходе на копии
- `test_people.php` - добровольные режимы и поиск физлиц только по полным ФИО
- `test_people_import.php` - очередь, повторы, смена среза и безопасное завершение большого импорта
- `test_cache.php` - сброс кеша всех помеченных страниц, включая архив больше 5000 статей

- `test_privacy.php` - счётчик до согласия, обновление старых настроек, включение и отключение заголовков, отдельная регистрация сайта

Проверка с настоящим WordPress на тестовом экземпляре:

    wp eval-file wp-content/plugins/legal-entity-marks/tests/integration-wordpress.php

Она использует синтетические записи и перехватывает сетевые обращения канала. Проверяет сохранение согласия через настоящую форму, поиск с кавычками и символами LIKE, пакетную запись JSON и удаление ссылок с сохранением слэшей. Созданные записи, настройки и расписание восстанавливаются в `finally`. Не запускать на рабочем сайте.

Сборка ZIP для WordPress.org из явного списка файлов:

    python3 bin/build-release.py --assets

В ZIP входят только код, CSS, комплектные JSON, переводимый шаблон, лицензия, readme и описание сервиса. Тесты, инструменты, старые архивы и материалы переезда остаются в рабочей папке. Иконки, баннеры и скриншоты для каталога находятся отдельно в `wordpress-assets/`.

- `test_uninstall.php` - сохранение данных по умолчанию и очистка через WordPress API только после явного выбора

Проверка сверки на настоящем WordPress и MySQL:

    wp eval-file wp-content/plugins/legal-entity-marks/tests/integration-registry-sync.php

82 проверки с синтетическими данными: все четыре категории, отсутствие и возврат
записей, ручные добавления, неполные и старые ответы, повреждённые даты,
откат при ошибке записи, параллельный запуск, длинные названия, пагинация
Минюста и переключение физических лиц только после полного перечня.
Таблицы плагина, настройки и очередь cron после прогона восстанавливаются.
Запускать на отдельном тестовом WordPress с отключённым автоматическим cron.
